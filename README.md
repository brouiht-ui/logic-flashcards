# Logic Flashcards

Quizlet-style study site for Arguments, Logic & Fallacies: 24 flashcards in 4 sets, a multiple-choice Learn mode, a 12-question practice test and a spaced-review study plan. Scores are saved in your browser.

- `index.html` is the whole site (static, no build needed to host).
- To edit cards, change `CARDS` in `make_flashcards.py`, then run `python build_site.py` (site) and `python make_flashcards.py` (printable PDF).

Unlock with your GitHub key

This page saves straight to your GitHub repo, so it needs a GitHub access key. The key is kept only in this browser on this device and is only ever sent to GitHub.

How to get a key (2 minutes)
  1. On GitHub go to Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → logic-flashcards.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Generate it, copy it, paste it above. Don't share it with anyone.
